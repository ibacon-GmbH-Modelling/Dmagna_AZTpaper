# Dmagna_AZTpaper
Repository with model and analysis scripts related to the article:
Trijau et al., Accounting for Experimental Variability in DEB-TKTD Modelling: Cross-Laboratory Calibration and Validation with Daphnia magna, 2026

The scripts are adaptations from the DEBtox2019 matlab package
developed by Tjalling Jager and publicly available here:
https://www.debtox.info/byom.html

The analysis was performed with BYOM version 6.5

The datafiles to use thesee scripts can be made available upon
request to the authors.
